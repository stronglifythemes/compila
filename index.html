El plan de estudios, semana a semana.

Cuatro módulos de cuatro semanas. Cada uno cierra con un proyecto que queda en tu portafolio.

  • Fundamentos de la web

    Estructura, estilos y control de versiones desde cero.

    HTML · CSS · Git

    → Tu página personal publicada

  • JavaScript

    Lógica, eventos y datos de otras APIs en el navegador.

    Servidores, bases de datos y cuentas de usuario.

    Node.js · Express · SQL

    → Tu propia API

  • Proyecto final

    Trabajo en equipo con revisión de código y entregas cada viernes.

    Git · Scrum · Despliegue

    → Demo ante empresas aliadas
